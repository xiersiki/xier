# Xier 界面整理

2026-10-25。目标是让已有的桌面对话功能更安静、精致，保留账号、历史记录、模型配置与同步行为。

## 视觉方向

“安静的对话工作台”：以文字为主角，保留 Xier 的紫色记忆，但把大面积高饱和气泡收成局部强调。

- 雾白 `#FAFAFC`：阅读底色。
- 银灰 `#F0F0F5`：侧栏。
- 墨色 `#292733`：正文。
- 石墨灰 `#777582`：次级文字。
- 鸢尾 `#78658F`：品牌；用户主题色继续影响控件。
- 细线 `#E3E2E9`：分界。

正文使用系统字体 / PingFang SC；品牌用 Avenir Next；欢迎标题用 Songti SC / Georgia（仅此一处），代码用 SFMono-Regular。界面文字 12–14px，回答随现有字号设置；标题按正文比例收敛。

## 布局选择

曾考虑保留图标轨道与会话双侧栏，但功能较少，分割会显得零碎。改为一个紧凑侧栏；聊天正文与输入框共用阅读宽度。

```text
┌─────────────────┬────────────────────────────────┐
│ xier            │ 对话标题                       │
│ ＋ 新对话        ├────────────────────────────────┤
│ 搜索             │                  用户的问题   │
│ 对话             │ Xier                           │
│ 标题             │ 清晰的回答与自然的段落         │
│   模型           │                                │
│                  │                                │
│                  │ ┌────────────────────────────┐ │
│ 账户             │ │ 输入消息                   │ │
│ 设置 · 主题       │ │ 模型                   ↑   │ │
└─────────────────┴─┴────────────────────────────┴─┘
```

签名元素是两条交织的曲线构成的 X 字标记，代表提问与回应。只在品牌、空态与回答署名中使用。取消装饰性大阴影、彩色整块回答与重复图标轨道，不增加虚构功能入口。

## 实现约束

保持浅色与深色完整配对；尊重现有字号、主题色、语言设置。保留会话搜索、重命名、置顶、批量操作、模型选择、停止生成、右键操作与同步。交互控件具备键盘焦点与标签；减少动态效果偏好生效。长内容、代码和表格不能撑破阅读宽度。
