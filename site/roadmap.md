# 路线图

以下区分已有能力和后续方向；没有发布版本与验收记录的项目不视为已交付。

## 已有能力

- OpenAI 兼容模型连接、模型列表获取与自定义模型 ID。
- 流式回答、取消、思考展示和独立的生成状态。
- 本地历史记录、访客与账号隔离、可选 Supabase 同步。
- 简洁桌面对话界面，优先验证 macOS Apple Silicon。

## 当前工程工作

- 建立可被新会话接手的 Agent 协作规则与 PR 流程。
- 用自动检查验证应用、文档和多平台桌面构建。
- 建立可追溯的测试发布与安装验收记录。

## 后续方向

- 完善各平台真实安装与回归验证，接入正式签名。
- 根据真实任务评估 Agent 工作台和后台自动化能力。

产品提案会先转成明确的 Issue 和验收条件，再安排实现。进度以 [GitHub Issues](https://github.com/xiersiki/xier/issues) 和 [Releases](https://github.com/xiersiki/xier/releases) 为准。
